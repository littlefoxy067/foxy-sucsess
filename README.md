# We've Got This — A Message from foxy 🦊

A mobile-friendly, single-page encouragement website for fellow KJSEA candidates.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Features
- Animated welcome screen and encouragement letter
- Optional background music that plays once per tap and does not repeat
- Persistent sound control, including on the letter screen
- Share button using Web Share API with clipboard fallback
- Responsive layout and reduced-motion support

## Deploy
This is a static site. It can be deployed to Vercel with no build command and the project root as the output directory.
